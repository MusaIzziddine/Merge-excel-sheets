# دمج ملفات الإكسل حسب رقم القطعة

تطبيق React (بدون backend) يدمج عدة ملفات Excel/CSV في ملف واحد حسب عمود مشترك (رقم القطعة).
كل المعالجة تتم داخل المتصفح باستخدام [SheetJS](https://sheetjs.com)، ولا تُرفع الملفات لأي خادم.

## المزايا
- رفع أي عدد من الملفات (‎.xlsx ‎.xls ‎.csv) واختيار الورقة وصف العناوين وعمود الربط لكل ملف.
- اكتشاف عمود «رقم القطعة» تلقائياً حتى لو اختلف ترتيب الأعمدة بين الملفات.
- مطابقة مرنة للأرقام: نص/رقم، مسافات، حروف كبيرة/صغيرة، أرقام عربية/إنجليزية.
- اختيار الأعمدة وترتيبها وإعادة تسميتها.
- خيارات: كل القطع / قطع الملف الأول فقط / القطع الموجودة في كل الملفات.
- جمع الكميات المكررة اختيارياً، وعمود «الإجمالي» كمعادلة إكسل.
- الملف الناتج باتجاه من اليمين لليسار مع فلاتر وعرض أعمدة مناسب.

## التشغيل محلياً
```bash
npm install
npm run dev      # http://localhost:5173
npm test         # اختبارات منطق الدمج
npm run build    # الناتج في dist/
```

## النشر
يُنشر تلقائياً على GitHub Pages عبر `.github/workflows/deploy.yml` عند كل push على `main`.
مرة واحدة فقط: من إعدادات الريبو ← Pages ← Source اختر **GitHub Actions**.

## البنية
- `src/merge.js` — منطق القراءة والدمج وبناء ملف الإكسل (دوال نقية قابلة للاختبار).
- `src/App.jsx` — الواجهة.
- `src/merge.test.js` — اختبارات Vitest.
